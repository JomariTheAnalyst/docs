## P1 — Add the Curator.io Facebook feed

**Goal:** Display approved SixthGear Facebook posts on the website using Curator.io so current social content can appear without being manually copied into the storefront.

<Info>
  Curator.io is the selected social media aggregator. This task should synchronize approved posts only; it should not expose private Facebook activity or make Facebook the source of product, pricing, or official policy information.
</Info>

### Decisions required before implementation

| Decision | What management must approve |
| --- | --- |
| Facebook source | Confirm the exact SixthGear Facebook Page source in Curator.io. Page mentions should not be mixed in unless intentionally approved. |
| Moderation | Choose automatic publishing or manual approval inside Curator.io. Manual approval is safer for the first release. |
| Website placement | Choose the homepage location and whether a separate Social Feed page is also needed. |
| Content types | Decide whether to show images, videos, Reels, text posts, or only selected formats supported by the feed. |
| Feed size | Approve the number of visible posts and whether a load-more action is allowed. |
| Branding | Approve card style, spacing, captions, dates, and the link back to Facebook. |
| Empty and error state | Approve what visitors see when Curator.io is unavailable or has no approved posts. |
| Privacy and tracking | Review any third-party cookies, scripts, analytics, or consent requirements introduced by the embed. |

### Implementation checklist

- [ ] Confirm the correct Facebook Page in Curator.io.
- [ ] Configure moderation and approval rules.
- [ ] Create the approved Curator.io feed.
- [ ] Decide whether the embed code or feed identifier belongs in Sanity, environment configuration, or a controlled website setting.
- [ ] Add a reusable social-feed component to the storefront.
- [ ] Place the feed in the approved homepage section.
- [ ] Preserve the current design, spacing, animations, and responsive behavior.
- [ ] Add loading, empty, and error states.
- [ ] Ensure the page remains usable when the third-party script is blocked.
- [ ] Confirm that the feed does not delay critical storefront content.
- [ ] Test approved Facebook image and video posts.
- [ ] Test desktop, tablet, and mobile layouts.
- [ ] Review accessibility for links, captions, focus order, and media labels.
- [ ] Review privacy and cookie-consent impact.
- [ ] Record the Curator.io owner account, handler, password custodian, MFA custodian, subscription, and renewal details in the credentials inventory.
- [ ] Capture screenshots and a synchronization video.
