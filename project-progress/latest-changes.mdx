## About and Services pages repaired

**Status:** Most recent work — prepared and awaiting final release

The About and Services pages were rewired so each section can be managed separately through SixthGear CMS. This gives the team better control and prevents one incomplete section from affecting the entire page.

The About page now supports separate control for:

- Hero
- Why Choose Us
- Our Story
- Our Space
- Company Values
- CEO Quote
- Call to Action

The Services page now supports separate control for:

- Hero
- Expertise
- Supported Brands
- Service List
- Service Process
- Gallery
- Call to Action

The work has passed the available system checks, but it still needs to be finalized, published, and checked on desktop and mobile before it is described as fully released.

**Status:** Added, awaiting final desktop and mobile verification

This gives customers a clearer way to request a service schedule without leaving the main website experience.

## Homepage content management expanded

**Status:** Added, with some sections still using backup website content

Most major homepage sections can now receive content from SixthGear CMS. This makes future text, image, and promotional updates easier for the team.

The connected areas include:

- Hero
- About Us
- Product Categories
- Services
- Satisfied Customers
- Franchise
- Client Testimonials
- Rider Stories
- Store Location
- CTA Banner
- Coffee Showcase
- Marquee
- Brands We Support
- Our Team

Some homepage sections can still show built-in backup content when the CMS content is missing or incomplete. Moving all approved homepage content into SixthGear CMS is listed as an important next task.

This is important because staff should always edit the correct main document instead of creating another version by mistake.

## Status guide

| Status | Meaning |
| --- | --- |
| Complete and checked | The change is available and its result has been confirmed. |
| Added, awaiting verification | The change is prepared but still needs a final website or CMS check. |
| Prepared, awaiting final release | The work exists but still needs to be finalized and published. |
| Partially complete | Some content or behavior still depends on backup website content. |
| Planned | The work has been approved as a direction but has not yet been added. |
