## Shop by Brands automated and redesigned

**Status:** Added in the current storefront work — final production and device verification still required

The homepage **Shop by Brands** section now loads Shopify collections automatically when their normalized handles begin with `brand-`. The section no longer depends on the custom featured-collection metafield and is no longer limited to four cards.

The collections are sorted alphabetically using their Shopify collection titles. Collections without an image remain visible and use a neutral placeholder instead of disappearing from the section.

The presentation was also updated:

- Brand cards use a consistent `4:5` image ratio.
- The carousel supports horizontal dragging.
- GSAP provides the movement and image parallax effect.
- The section can show all matching brand collections instead of a fixed group of four.

## Featured video section added

**Status:** Added in the current storefront work — final content, playback, and production verification still required

A responsive featured-video section was added underneath the homepage marquee. Its default content uses the SixthGear trailer hosted on Cloudinary.

The section includes:

- A centered play and pause button
- An overlay title
- A description
- A call-to-action button
- Responsive sizing for desktop and mobile

The main play and pause icon uses GSAP MorphSVG to animate between both states. After playback begins, the icon, title, description, and controls fade away after approximately one second.

The controls return when:

- The video is paused
- The user moves or hovers over the player
- A control receives keyboard focus

## Featured video connected to SixthGear CMS

**Status:** Added in the current storefront work — final CMS publishing demonstration still required

The complete featured-video section is now connected to SixthGear CMS. Editors can control whether the section is shown and whether it uses CMS-managed content.

Editors can provide video content by:

- Uploading a video directly to Sanity
- Entering an approved Cloudinary URL
- Entering a supported YouTube URL

Supported YouTube formats include standard watch links, shortened links, Shorts, live videos, embed links, and privacy-enhanced YouTube links.

Editors can also configure:

- Poster image
- Video title
- Description
- Accessibility label
- Starting mute state
- Looping behavior
- Call-to-action label
- Call-to-action link

Internal and external CTA links are supported.

A content-selection layer validates the CMS data before rendering it. Invalid, incomplete, or unavailable CMS video content falls back to the original SixthGear Cloudinary trailer so the section does not break or disappear unexpectedly.

The section also supports Sanity visual editing.

## Status guide

| Status | Meaning |

| Complete and checked | The change is available and its result has been confirmed. |
| Added, awaiting verification | The change is prepared but still needs a final website or CMS check. |
| Prepared, awaiting final release | The work exists but still needs to be finalized and published. |
| Partially complete | Some content or behavior still depends on backup website content. |
