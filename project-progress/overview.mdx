## Current project position

| Area | Current position | Management meaning |
| --- | --- | --- |
| Shopify commerce | Implemented in the storefront | Shopify remains the source for products, collections, carts, customer accounts, orders, and hosted checkout. |
| Homepage CMS | Implemented, awaiting browser and content verification | Most editorial homepage sections have Sanity schemas, queries, and storefront consumers. |
| About page CMS | Implemented but uncommitted | Automated checks pass, but the work must be reviewed, committed, and tested before deployment. |
| Services page CMS | Implemented but uncommitted | Independent CMS controls exist, but the work is not yet deployable. |
| Sanity Visual Editing | Foundation implemented; live workflow unverified | Draft Mode, Presentation, editing markers, and live configuration exist. A real editing session still needs to be recorded. |
| Cal.com booking | Implemented, awaiting desktop and mobile verification | Booking entry points open the Cal.com modal, but failure handling and final responsive behavior still need testing. |
| Social media feed | Planned | Curator.io will be used to display approved Facebook posts on the website. |
| Browser testing | Not reliably verified | The stored Playwright run failed because Chromium was missing, not because the storefront was proven broken. |
| Continuous integration | Blocked | GitHub Actions still uses `npm ci` even though pnpm is now the project package manager. |
| Vercel ownership | Not verified | The repository shows Vercel intent, but not the production project owner, production branch, domains, or rollback authority. |
| Management access | Ready for live verification | Shopify, CMS, source code, product CSV, and credentials handoff guides are available. |
