Use this page when management needs the current SixthGear product list or when an updated Shopify product export must be created.

## Current product CSV

[Open the SixthGear product CSV in Google Drive](https://drive.google.com/file/d/15jRTA_Q41eBIoKkbwuayPXUFwMMUNR-W/view?usp=drive_link)

<Info>
  Access to the file depends on the sharing permissions set in Google Drive. Keep the file limited to approved company users.
</Info>

A **CSV** is a simple spreadsheet-style file used to store information in rows and columns. The file extension is **`.csv`**, which means **Comma-Separated Values**. It can be opened in Microsoft Excel, Google Sheets, and other spreadsheet applications.

The SixthGear product CSV is a dated copy of the product information exported from Shopify. It may include product titles, descriptions, handles, variants, prices, SKUs, inventory fields, publication details, and other Shopify product columns.

<Warning>
  The CSV is a reference and recovery file. Shopify remains the live source of truth for current products, prices, variants, and inventory. Do not edit the CSV and assume the live store has changed.
</Warning>

## When to create a new export

Create a new product CSV when:

- Management requests an updated product list.
- A major product or pricing update has been completed.
- A migration, audit, or recovery copy is needed.
- The current Google Drive copy is no longer up to date.
- A controlled bulk review is planned.

## Before you export

- Confirm that you are signed in to the correct SixthGear Shopify store.
- Use **All products** for a complete management copy unless a smaller scope is approved.
- Use a company-controlled device.
- Record the export date and the person who completed it.
- Save the approved file in the controlled SixthGear Google Drive location.

## Export the product CSV

<Steps>
  <Step title="Open Products">
    In Shopify Admin, open **Products**.
  </Step>
  <Step title="Select Export">
    Select **Export** from the Products page.
  </Step>
  <Step title="Choose the scope">
    Select **All products** for the complete management handoff. Use selected products or the current page only when that smaller scope is approved.
  </Step>
  <Step title="Choose the file format">
    Select the CSV format intended for spreadsheet programs when management will open the file in Excel or Google Sheets.
  </Step>
  <Step title="Request the export">
    Confirm the export. Shopify may download the file or send it to the signed-in account.
  </Step>
  <Step title="Open and check the file">
    Confirm that the CSV opens correctly and includes the expected product titles, variants, prices, SKUs, inventory information, and publication fields.
  </Step>
  <Step title="Store the approved copy">
    Upload the checked file to the controlled Google Drive location and update the handoff record below.
  </Step>
</Steps>

| Export date | To record |

| Shopify store | SixthGear Moto Shopify store |
| Export scope | All products / selected products / current page |
| File name | To record |
| Product count at export | To record |
| Reviewed by | To record |
| File opened successfully | Yes / No |
| Verification status | Pending / Verified |

## Recommended file name

```text
sixthgear-shopify-products-YYYY-MM-DD.csv
```

## Verify the handoff

- Management can open the Google Drive link.
- The CSV opens without broken columns or unreadable characters.
- The export date and scope are recorded.
- Sharing is limited to approved company users.
- Shopify is understood as the live source of truth.
- The CSV is understood as a dated reference, audit, and recovery copy.
