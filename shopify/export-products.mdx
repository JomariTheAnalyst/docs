Use this procedure when management needs a current copy of the SixthGear Shopify product catalog in CSV format.

## Shopify link

<CodeGroup>

```text Shopify Admin
https://sixthgearmoto.myshopify.com/admin
```

</CodeGroup>

## Before you export

- Confirm that you are signed in to the correct SixthGear Shopify store.
- Use **All products** for the executive handoff unless management approves a smaller scope.
- Use a company-controlled device and approved storage location.
- Record the export date and person who completed the export.

<Warning>
  A product CSV can contain operational catalog data. Do not upload the export to Mintlify, a public repository, a public link, or a personal drive.
</Warning>

## Export the product CSV

<Steps>
  <Step title="Open Products">
    In Shopify Admin, open **Products**.
  </Step>
  <Step title="Select Export">
    Select **Export** from the Products page.
  </Step>
  <Step title="Choose the scope">
    Select **All products** for the complete management handoff. Use selected products or the current page only when that narrower scope is approved.
  </Step>
  <Step title="Choose the file format">
    Select the CSV format intended for spreadsheet programs when management will open the file in Excel.
  </Step>
  <Step title="Request the export">
    Confirm the export. Shopify may download the file or send the export to the signed-in account.
  </Step>
  <Step title="Open and verify the file">
    Open the CSV and confirm that product titles, handles, variants, prices, SKUs, inventory fields, status, and publication fields are present.
  </Step>
  <Step title="Store the approved copy">
    Save the file in controlled company storage and record the exact location without publishing an unrestricted download link.
  </Step>
</Steps>

## Handoff record

| Field | Record |
| --- | --- |
| Export date | To record |
| Exported by | To record |
| Shopify store | SixthGear Moto Shopify store |
| Export scope | All products / selected products / current page |
| File name | To record |
| Product count at export | To record |
| Controlled storage location | To record |
| Reviewed by | To record |
| File opened successfully | Yes / No |
| Verification status | Pending / Verified |

## Recommended file name

```text
sixthgear-shopify-products-YYYY-MM-DD.csv
```

## Verify the handoff

- Management can access the controlled storage location.
- The CSV opens without corrupt columns or character issues.
- The export scope and date are recorded.
- The file is not exposed through a public link.
- Shopify remains the live product source of truth.
- The CSV is understood as a dated reference and recovery asset.
