Use this procedure when management needs a current copy of the SixthGear product catalog in CSV format.

<Warning>
  Product CSV files can contain operational catalog data. Do not upload the export to a public link, personal drive, public repository, or Mintlify.
</Warning>

## Export the product CSV

<Steps>
  <Step title="Open Products">
    In Shopify Admin, open **Products**.
  </Step>
  <Step title="Choose the export scope">
    Select **Export**. Choose **All products** for a full management handoff unless a smaller scope was approved.
  </Step>
  <Step title="Choose the CSV format">
    Use the CSV format intended for spreadsheet programs when management will review the file in Excel.
  </Step>
  <Step title="Request the export">
    Confirm the export. Shopify may download the file immediately or email a download link to the signed-in account.
  </Step>
  <Step title="Open and verify the file">
    Open the CSV in Excel. Confirm that product titles, handles, variants, prices, SKUs, inventory fields, status, and publication fields appear as expected.
  </Step>
  <Step title="Store the approved copy">
    Save the verified export in the controlled company storage location using the approved file-naming convention.
  </Step>
</Steps>

## Handoff record

| Field | Record |
| --- | --- |
| Export date | To record |
| Exported by | To record |
| Store | SixthGear Shopify store |
| Scope | All products / selected products / filtered view |
| File name | To record |
| Controlled storage location | To record without exposing a public download URL |
| Reviewed by | To record |
| Verification status | Pending / Verified |

## Recommended file name

```text
sixthgear-shopify-products-YYYY-MM-DD.csv
```

## Verify the handoff

- Management can access the controlled storage location.
- The CSV opens without corrupt columns or character issues.
- The export scope and date are recorded.
- No public or unrestricted link was created.
- The file remains a reference copy. Shopify remains the live source of truth.
