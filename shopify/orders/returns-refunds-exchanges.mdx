Use this guide when a customer asks to send an item back, receive money back, or replace an item with another product or variant.

<Info>
  Go to **Shopify Admin → Orders**, find the original order, and review it before starting any return, refund, or exchange.
</Info>

<Warning>
  Do not promise, approve, refund, exchange, or restock an item until the original order, payment, item condition, and approved SixthGear return policy have been checked.
</Warning>

## Know the difference

| Action | What happens |
| --- | --- |
| **Return** | The customer gives an item back to SixthGear. The item may or may not be added back to sellable stock. |
| **Refund** | SixthGear sends all or part of the payment back to the customer. A refund does not always mean an item was physically returned. |
| **Exchange** | The customer returns an item and receives a different product, size, color, or variant. The price difference may require a refund or an additional payment. |

<Note>
  These actions are connected, but they are not the same. Staff must record each action correctly so the customer payment and inventory are not changed twice.
</Note>

## Before starting

Confirm all of the following:

- Correct SixthGear Shopify store
- Original order number and customer
- Product, variant, quantity, and selling price
- Original payment method and payment status
- Fulfillment or pickup status
- Whether the item was already returned, refunded, exchanged, or restocked
- Customer's reason for the request
- Item condition and whether all parts or accessories are present
- Approved SixthGear return period and eligibility
- Person authorized to approve the action
- Correct location for returned stock

<Warning>
  The current documentation does not set a new return period, restocking fee, or final-sale rule. Follow the approved SixthGear return policy. If the policy or approval is unclear, stop and ask management before processing the request.
</Warning>

## Staff permissions and approval

The staff member must have the required Shopify order and refund permissions. Access to the button does not automatically give business approval.

Do not continue without approval when the request involves:

- Refund to the original payment method
- Refund to store credit
- A refund larger than the eligible amount
- An item outside the approved return period
- A damaged, used, incomplete, or missing item
- A missing receipt or unverified order
- A price exception
- A return fee or restocking fee
- A payment collected outside Shopify
- A chargeback or payment dispute

## Review the request

<Steps>
  <Step title="Find the original order">
    In **Orders**, search by order number, customer name, email, product, or other available order details. Do not create a new order to replace the original record.
  </Step>
  <Step title="Confirm the customer and item">
    Match the customer, product, variant, quantity, price, payment method, fulfillment status, and order date.
  </Step>
  <Step title="Check earlier actions">
    Review the order timeline for earlier returns, refunds, exchanges, cancellations, stock changes, notes, or payment actions.
  </Step>
  <Step title="Check the approved return policy">
    Confirm that the item and request are eligible. Record the reason and obtain approval when an exception is required.
  </Step>
  <Step title="Inspect the item when returned">
    Check the actual product, variant, condition, packaging, accessories, serial or identifying details when used, and whether it can be sold again.
  </Step>
  <Step title="Choose the correct action">
    Decide whether the request requires a return only, refund, exchange, or a combination. Do not select every action automatically.
  </Step>
</Steps>

## Create and process a return

Use a return when the fulfilled item is expected to come back to SixthGear.

<Steps>
  <Step title="Open the order return action">
    Open the original order and select the return action available for the order.
  </Step>
  <Step title="Select the correct items and quantities">
    Include only the products the customer is returning. Check the exact variant and quantity.
  </Step>
  <Step title="Record the reason">
    Select or enter the most accurate return reason and add a short note when needed.
  </Step>
  <Step title="Give the approved return instructions">
    Provide the customer with the approved in-store, delivery, or shipping instructions. Do not invent a courier, address, or fee.
  </Step>
  <Step title="Wait for and inspect the item">
    Do not treat an item as received only because a return was created. Inspect the actual item before restocking or completing the return.
  </Step>
  <Step title="Process only received items">
    If only part of the return has arrived, process only those items and leave the remaining items open for follow-up.
  </Step>
  <Step title="Choose the correct restock decision">
    Restock the item only when it is physically received, complete, sellable, and assigned to the correct location.
  </Step>
  <Step title="Complete or close the return">
    Confirm that all received items, exchange items, payment actions, and remaining tasks are correct before closing the return.
  </Step>
</Steps>

## Restock safely

A returned item should be added back to available stock only when it can be sold again.

| Item condition | Staff action |
| --- | --- |
| Unopened, complete, and sellable | Restock at the approved location after inspection |
| Opened but still approved for resale | Obtain approval and confirm the correct stock classification |
| Damaged, used, incomplete, or missing parts | Do not return it to normal sellable stock |
| Wrong item received | Stop and verify the order and product before any stock change |
| Item not physically received | Do not restock |
| Already restocked through another action | Do not restock again |

<Warning>
  Restock only once. A refund, cancelled fulfillment, POS return, manual stock adjustment, or Shopify return may already have changed inventory. Check the order timeline and inventory history first.
</Warning>

## Issue a full or partial refund

Use a refund when SixthGear owes money back to the customer and the action has been approved.

<Steps>
  <Step title="Open the original order">
    Confirm the order, customer, payment method, refundable amount, and previous refunds.
  </Step>
  <Step title="Select the correct items or amount">
    For a partial refund, include only the approved items, quantities, shipping amount, or adjustment.
  </Step>
  <Step title="Review the refund method">
    Use the approved refund method shown for the order. Do not move the refund to another method or store credit without authority.
  </Step>
  <Step title="Review the restock option">
    Select restock only when the item was actually returned and approved for resale. Do not use the refund screen to guess inventory.
  </Step>
  <Step title="Review the customer notification">
    Confirm whether Shopify should send the refund notification and check the customer's contact information.
  </Step>
  <Step title="Confirm before submitting">
    Recheck the items, quantities, refund amount, payment method, shipping refund, restock location, and notification.
  </Step>
  <Step title="Verify the result">
    Reopen the order and confirm the refund amount, payment status, timeline, inventory effect, and any remaining balance.
  </Step>
</Steps>

<Warning>
  Shopify can allow a refund without creating a return, but a return cannot be created after the refund has already been issued for those items. When the physical item must come back, create and manage the return before issuing the final refund.
</Warning>

## Process an exchange

Use an exchange when the customer returns one item and receives another item or variant.

<Steps>
  <Step title="Confirm the original item">
    Check the original product, variant, quantity, price, payment, and condition.
  </Step>
  <Step title="Confirm the replacement item">
    Check the requested product or variant, available stock, selling price, and customer approval.
  </Step>
  <Step title="Create the return and add the exchange item">
    Use the order's return or exchange workflow. Record both the returned item and the replacement item in the same approved process when supported.
  </Step>
  <Step title="Review the price difference">
    Confirm whether SixthGear owes the customer a refund, the customer owes an additional payment, or the values are equal.
  </Step>
  <Step title="Receive and inspect the returned item">
    Do not restock it until it has been physically received and approved for resale.
  </Step>
  <Step title="Prepare the replacement">
    Pick the correct product, size, color, model, and quantity. Inspect it before release.
  </Step>
  <Step title="Complete the payment action">
    Issue the approved refund or collect the approved balance through the proper process.
  </Step>
  <Step title="Release or fulfill the exchange item">
    Mark only the replacement item actually prepared, shipped, delivered, or handed over.
  </Step>
  <Step title="Verify the final order">
    Confirm the returned item, replacement item, stock changes, refund or payment, and final fulfillment status.
  </Step>
</Steps>

## In-store Shopify POS requests

When Shopify POS is used, returns and exchanges must be opened from the original order whenever possible.

- Confirm the POS location and staff permissions.
- Select the exact returned items and quantities.
- Record the return reason.
- Restock only at the approved location and only when the item is sellable.
- Refund no more than the amount paid through the selected payment method.
- Confirm the receipt and final order record.
- Do not process the same return in both Shopify Admin and Shopify POS.

<Note>
  Shopify POS exchange tools and some return controls can depend on the POS plan and staff permissions. Use only the functions available and approved for SixthGear's active setup.
</Note>

## Special situations

### Customer requests a refund before returning the item

- Check the approved return policy.
- Do not promise an early refund without approval.
- When the item must be returned, create the return and wait for inspection before completing the refund.

### Item was never fulfilled

- Confirm that the item was not shipped, delivered, or picked up.
- Follow the approved cancellation or refund process.
- Check whether Shopify already restored inventory.

### Only part of the order is returned

- Select only the returned items and quantities.
- Leave the remaining products unchanged.
- Confirm the remaining paid and fulfilled order information.

### Returned item is damaged or incomplete

- Do not put it back into normal sellable stock.
- Record the condition and missing parts.
- Ask the authorized person to decide the refund, exchange, fee, or rejection.

### Payment was made outside Shopify

- Check the external provider record and Shopify order notes.
- Do not assume Shopify can send the money back automatically.
- Finance or the responsible payment owner must confirm the refund method and settlement effect.

### Customer has no order number

- Search using approved order details.
- Confirm the customer and purchase before processing.
- Do not create an unverified return unless the staff member has permission and management approval.

## Staff boundaries

Do not do these without the required approval:

- Approve an ineligible or late return
- Issue a refund
- Refund to a different method or store credit
- Over-refund an order
- Apply or remove a return fee
- Accept a damaged or incomplete product as normal sellable stock
- Create an unverified return
- Change customer, item, or price details to force an exchange
- Restock an item that has not been received
- Process the same action in Shopify Admin, Shopify POS, Loyverse, or another system twice
- Delete order notes, timeline entries, or evidence

- [ ] Original order and customer confirmed
- [ ] Approved return policy checked
- [ ] Correct items, variants, and quantities selected
- [ ] Return reason recorded
- [ ] Item condition checked
- [ ] Restock decision and location are correct

- [ ] Order timeline and final status are correct
