Loyverse can be removed only when every feature the store uses is covered. See [The Shopify POS decision](/reports-and-management/pos-decision). Update this table when a status changes.

## Status meanings

| Status | Meaning |
| --- | --- |
| **Built in** | Shopify POS does it without extra apps |
| **Workaround** | Shopify does it differently. The way it is done is decided |
| **App needed** | Shopify needs an extra app. No app is chosen yet |
| **Pending decision** | Management has not decided yet |

## The checklist

| Loyverse feature | Shopify status | How it works in Shopify |
| --- | --- | --- |
| Selling by category | **Built in** | Every product has a business unit and a report category |
| Services as products | **Built in** | Services, carwash, and hauling are products. See [Services, carwash, and hauling](/at-the-counter/services-carwash-hauling) |
| Discounts | **Built in** | 10%, 15%, 20%, and the executive discount. See [Discounts](/at-the-counter/discounts) |
| Shift cash tracking | **Built in** | The cash drawer session. See [Open and close the register](/at-the-counter/open-and-close-register) |
| Refunds | **Built in** | Shopify can do refunds. The SixthGear refund process is still a pending decision, see below |
| Offline cash sales | **Built in** | Cash sales work without internet. Discounts, returns, and customer lookup can need a connection |
| Changing prices | **Workaround** | A ₱1 item, with the amount entered as the quantity |
| Care of Boss | **Workaround** | A payment method. It is a full-price sale, and the owner reimburses the store |
| Custom sale | **Workaround** | Not allowed. Every item must be a product with a category |
| Café add-ons, such as an extra shot | **App needed** | No app chosen yet |
| Kitchen or bar order printing | **App needed** | No app chosen yet |
| Open tabs for café tables | **App needed** | No app chosen yet |
| Loyalty points | **App needed** | No app chosen yet |
| Employee time clock | **App needed** | No app chosen yet |
| Ingredient stock tracking | **App needed** | No app chosen yet |
| Refund process | **Pending decision** | See [Decisions still open](/reports-and-management/open-decisions) |
| Official BIR receipts | **Pending decision** | See [Decisions still open](/reports-and-management/open-decisions) |
