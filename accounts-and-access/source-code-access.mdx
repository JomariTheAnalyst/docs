## Grant management access

<Steps>
  <Step title="Confirm the management GitHub account">
    Use a named account controlled by the approved person. Do not share one developer login between multiple people.
  </Step>
  <Step title="Invite the account">
    The repository owner opens **Settings → Collaborators and teams** and sends an invitation with the approved role.
  </Step>
  <Step title="Accept the invitation">
    Management signs in to GitHub and accepts the repository invitation.
  </Step>
  <Step title="Verify the repository">
    Open `sixthgear-shopify` and confirm that the `main` branch is visible.
  </Step>
  <Step title="Verify the role">
    Confirm whether the account can only view code or can also manage settings, members, branches, and security controls.
  </Step>
</Steps>

## Management verification checklist

- The correct repository opens.
- The `main` branch is visible.
- Management's role matches the approved responsibility.
- At least one approved backup administrator is assigned.
- Repository ownership will remain under company control if the current developer leaves.
- Branch protection and merge authority are reviewed.
- Vercel deployment access is documented separately because GitHub access alone does not provide production control.
