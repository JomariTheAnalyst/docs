The SixthGear website gets its content from three places. Before you change anything, find the part of the website in the tables below. The table tells you where to make the change.

- **Shopify admin** holds the products and everything about them.
- **The CMS** holds the words, photos, and banners on the website pages. CMS stands for content management system. At SixthGear, the CMS is called **Sixthgear CMS**. It is Sanity Studio, and you open it at `/studio` on the website.
- **The website code** holds a few fixed parts. Only the web team can change those.

## Change these in Shopify admin

| Part of the website | What to change in Shopify admin |
| --- | --- |
| Products, prices, and stock | The product itself |
| Collection pages | The collection |
| The brand carousel | Collections whose handle starts with `brand-`. A handle is the short name in a page's web address |
| The Featured and Best Sellers rails on the home page | Products with the tag `featured` |
| Product badges | Products with the tag `hot-deal` or `new-arrival` |

For products and stock, see the [Products and Stock](/products-and-stock/overview) tab.

## Change these in the CMS

| Part of the website | Where to find it in the CMS |
| --- | --- |
| Home page hero, the big banner at the top | **Homepage Settings** |
| Home page video | **Homepage Settings** |
| Home page about section | **Homepage Settings** |
| Product categories | **Homepage Settings** |
| Services list on the home page | **Homepage Settings** |
| Team | **Homepage Settings** |
| Testimonials, the customer reviews | **Homepage Settings** |
| Rider stories | **Blog**, then **Blog Posts** |
| Store location section on the home page | **Homepage Settings** |
| Call-to-action banner, the last banner on the home page | **Homepage Settings** |
| Pop-up | **Popup Ad Campaign** and **Marketing** |
| Promo banners and featured collection banners | **Marketing** |
| The announcement bar at the very top | **Marketing** |
| The Services page | **Services Page**, and **Services** for each service |
| The About page | **About Page** |
| Blog posts | **Blog**, then **Blog Posts** |

<Info>
  At SixthGear, rider stories and blog posts are the same thing. Every blog post shows on the website as a rider story.
</Info>

## Only the web team can change these

The scrolling marquee strip, the "Recommended collections" section, page SEO titles, the Contact page store details, footer business details, the First Gear Coffee page, and the Shop page title. See [Things only the web team can change](/website-content/web-team-only).

<Warning>
  The store location in the CMS changes the home page only. It does not change the Contact page or the footer. See [Known issue: store location](/website-content/web-team-only#known-issue-store-location).
</Warning>
