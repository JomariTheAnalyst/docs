Some parts of the website are written into the website code. You cannot change them in the CMS or in Shopify admin. Send these requests to the web team.

## What only the web team can change

| Part of the website | Where you see it |
| --- | --- |
| The scrolling marquee strip | The moving strip of text on the home page |
| The "Recommended collections" section | The home page |
| Page SEO titles, the page names shown in Google and in the browser tab | Every page |
| Store details on the Contact page | The Contact page |
| Business details in the footer | The bottom of every page |
| The First Gear Coffee page | The First Gear Coffee page |
| The Shop page title | The top of the Shop page |

## Known issue: store location

Changing the store location in the CMS updates the store location section on the home page only. It does not change the Contact page or the footer. Those use fixed details in the website code.

<Warning>
  If the store address, phone number, or opening hours change, update the CMS and also ask the web team to update the Contact page and the footer. Otherwise the website will show two different addresses.
</Warning>

## How to ask for a change

Send the web team:

1. The page address, for example the link to the Contact page.
2. What the page says now.
3. What it should say, with the exact new wording.
4. Who approved the change.
